A task and habit tracker with a calendar view and drag-and-drop reordering. The Spring Boot API has 13 endpoints and runs in Docker on Render. The Next.js frontend is linked above, and the API is in [Dawam-Tasks-Backend](https://github.com/xAdhm/Dawam-Tasks-Backend).

**[Turaath Books](https://turaathbooks.com)**
A live bookstore with a 395+ book catalog, Stripe and Zelle payments, and an admin dashboard. The code is private.

**Rise and Shine HR platform**
The backend for an internal HR system I built as an intern, with role-based access, Postgres Row-Level Security, field-level encryption, and a hash-chained audit log. Private company project, built on test data.

**Luqmah**
In progress. A barcode scanner that flags ambiguous ingredients like gelatin and enzymes, then emails the manufacturer to ask whether they're animal-derived.
